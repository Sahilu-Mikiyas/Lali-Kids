# Lali (ላሊ)

Stories and learning for Ethiopian kids aged 3 to 9, in English and Amharic.

Lali gives families a better alternative to endless YouTube scrolling: beautiful,
narrated storybooks that build a reading habit, plus animated learning content for
English, basic maths and values. Parents pay a monthly subscription.

## What's in this repo

| Folder | What it holds |
|---|---|
| `docs/ROADMAP.md` | The plan: phases, next steps and what we measure |
| `docs/BRAND.md` | Name, mascot, characters, voice and pricing draft |
| `docs/research/` | Market and content research (YouTube channel study, competitors) |
| `web/prototype/` | The first clickable website prototype (open `index.html` in a browser) |

The app and website code will live in `apps/` once we choose the tech stack
(see the roadmap).

## Try the prototype

Open `web/prototype/index.html` in any browser. It includes the animated home page,
a four-page read-along story, the star-counting game, the parents' section and plans.
